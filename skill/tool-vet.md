# 工具上机审查（dsh-tool-vet）

**什么时候用**：要装一个不熟悉的 DSH 插件、npm 包或第三方工具，想先知道它会动什么。
用户会说：「这个插件安全吗」「装这个东西会不会有问题」「帮我看看这个包干什么的」。

## 怎么用

```bash
dsh-tool-vet --root <包目录>
```

## 怎么读结果

它**只列能力，不下结论**。看到命中时，按这个顺序想：

1. **装时自动执行**（`VET-INSTALL-SCRIPT`）—— 先打开那段脚本看一眼。只编译/生成文件的可以接受；下载东西、读用户目录、连网络的不要装。
2. **读凭据路径**（`VET-CRED-PATH`）—— 问一句「它为什么要读这个」。正经插件不需要你的私钥和 token。
3. **拼接执行**（`VET-OBFUSCATION`）—— 作者不想让你看懂他干了什么。别装。
4. **出网 / 执行命令 / 非 registry 依赖** —— 不一定有问题，但要知道。

## 不要做什么

- 不要把「命中」当成「有问题」—— 一个 git 工具当然要执行 `git`，一个 SSH 工具当然要读 `.ssh`
- 不要指望它拦运行时行为 —— 它不拦截，只审查
